# 技術発信の継続

**項目No.：097〜100**

回答例は望ましい状態を示す架空の文面です。[判定方法](../guide/team-assessment.md)と[記録書式](../templates/team-assessment.md)を使い、実態と根拠を記録してください。

## この分野の背景

この分野は、チームが得た技術的な知見をブログ、勉強会、外部イベントでの発表などを通じて社外に発信し、それを続けていく取り組みを扱います。モバイル開発では、毎年のOS更新で新しい機能や制約が一斉に加わるため、対応で得た知見を整理して発信する価値が高くなります。また、iOSとAndroidそれぞれに開発者のコミュニティがあるため、発信は採用活動にも役立ちます。一方で、少人数でiOSとAndroidに分かれたチームでは、発信が得意な一人に頼りがちで、その人が抜けると活動が途絶えやすくなります。まず、直近1年の発信を誰が担当したかを一覧にし、担当が偏っていないかを確認してください。

分からない用語は[用語集](../guide/glossary.md)で確認できます。

## C097

**チェック項目 No.097**

チーム全体で発信の方針を定め、それに基づいて定期的（月ごと〜半年ごと）に発信数やインプレッション関連指標をモニタリングしている。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

発信の目的、対象読者、iOS・Androidなどのテーマ、チャネル、公開頻度をチームで定めています。月次で発信数、閲覧数、インプレッション（記事や投稿が表示された回数）などを確認し、目的に応じてモバイルエンジニアの採用応募や問い合わせとの関係も評価しています。結果を基に企画と発信方法を見直し、担当者と次の実施時期を決めています。

[原文の参照先](https://dxcriteria.cto-a.org/a795f6d9cea2461198ed24686b7641f9)

## C098

**チェック項目 No.098**

発信内容についてレビュープロセスを設けて社内での議論や学習を促している。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

発信内容には技術的な正確性、読み手の理解、未発表の機能やベータ版OS（正式公開前に開発者へ配られるOS）の守秘対象となる情報を含まないかを確認するレビュープロセスを設けています。執筆者とレビュアーを決め、指摘と修正理由を記録しています。レビューで得た知見はチーム内に共有し、発信を実務の振り返りと学習の機会にしています。

[原文の参照先](https://dxcriteria.cto-a.org/74080a0af5104c80871932e7ba299878)

## C099

**チェック項目 No.099**

テックブログや勉強会の開催、外部イベントへの登壇など複数チャネルにおける発信のチーム内実績がある。

**望ましい原文への回答：TRUE**

原文にある取り組みを実施している状態を目指します。

### 望ましい回答例

直近1年間に、テックブログ、勉強会、iOSDC Japan（iOS開発者向けの国内カンファレンス）やDroidKaigi（Android開発者向けの国内カンファレンス）などの外部イベントといった複数のチャネルでチームとして発信した実績があります。WWDC（Appleが毎年開催する開発者向け会議）・Google I/O（Googleが毎年開催する開発者向け会議）の後には、新しいOS機能の検証結果を共有する勉強会も開催しています。公開URL、開催日、担当者、対象読者を一覧化し、資料を再利用できるようにしています。発信後の反応と得られた知見を共有し、次の企画に反映しています。

[原文の参照先](https://dxcriteria.cto-a.org/2316c5f0e3d44877aa14c0749f42d62b)

## C100

**チェック項目 No.100**

外部発信の活動が特定の個人に依存しており、チーム全体で持続可能な取り組みになっていない。

**望ましい原文への回答：FALSE**

原文にある問題が発生していない状態を目指します。

### 望ましい回答例

発信を特定の個人の自主活動だけに依存させず、企画、執筆、レビュー、公開の役割と作業時間をチームで確保しています。iOS・Android・React Nativeの各担当から発表者を育成するため、共同執筆や共同登壇、テンプレート、レビュー支援を用意しています。四半期ごとに担当の偏りと継続状況を確認し、無理なく継続できる計画へ見直しています。

[原文の参照先](https://dxcriteria.cto-a.org/fac5f7f0244f4e4699102ee484b644fb)
