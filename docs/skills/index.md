# 要素技術の定義

要素技術は4つの領域に分類します。領域は資格の序列ではなく、担当業務と前提知識に応じて組み合わせるためのまとまりです。各要素技術には対象プラットフォーム（共通、iOS、Android、React Native）を付けています。担当するプラットフォームの要素技術と共通要素技術を組み合わせて評価します。

各要素技術にはLv0〜Lv4の到達状態を定義しています。根拠が足りない場合の「未評価」はLv0と区別します。[個人の評価方法](../guide/individual-assessment.md)と併せて確認してください。
