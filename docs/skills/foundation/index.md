# 基礎領域

この領域に含まれる要素技術6件を示します。対象はプラットフォーム（共通、iOS、Android、React Native）を示します。前提知識は学習の目安であり、同じ習熟度への到達を一律に要求するものではありません。

| 要素技術ID | 要素技術 | 対象 | 評価対象・主な前提 |
| :--- | :--- | :--- | :--- |
| `mobile.basic` | [モバイルプラットフォーム基礎](mobile.basic.md) | 共通 | OS構成、アプリライフサイクル、サンドボックス、権限、配布形態 |
| `swift.basic` | [Swift](swift.basic.md) | iOS | 構文、Optional、クロージャ、構造体・クラス、プロトコル、エラー処理 |
| `kotlin.basic` | [Kotlin](kotlin.basic.md) | Android | 構文、Null安全、クラス・データクラス、コレクション、拡張関数 |
| `ide.basic` | [開発環境（Xcode／Android Studio／Expo）](ide.basic.md) | 共通 | プロジェクト構成、ビルド実行、デバッガ、シミュレータ・エミュレータ |
| `build.tooling` | [ビルドと依存管理](build.tooling.md) | 共通 | ビルド設定、依存関係の追加・更新、成果物の生成 |
| `git.basic` | [Git](git.basic.md) | 共通 | branch、commit、merge、rebase |
