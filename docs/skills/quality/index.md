# 品質・高度化領域

この領域に含まれる要素技術8件を示します。対象はプラットフォーム（共通、iOS、Android、React Native）を示します。前提知識は学習の目安であり、同じ習熟度への到達を一律に要求するものではありません。

<!-- catalog:start -->

| 要素技術ID | 要素技術 | 対象 | 評価対象・主な前提 |
| :--- | :--- | :--- | :--- |
| `test.design` | [テスト設計](test.design.md) | 共通 | 各テスト実装 |
| `test.unit` | [ユニットテスト](test.unit.md) | 共通 | Swift、Kotlin、またはTypeScript |
| `test.ui` | [UIテスト・E2E](test.ui.md) | 共通 | UI実装、テスト設計 |
| `mobile.performance` | [性能・メモリ・起動時間](mobile.performance.md) | 共通 | 並行処理、UI実装 |
| `mobile.security` | [モバイルセキュリティ](mobile.security.md) | 共通 | ネットワーク通信、データ永続化 |
| `mobile.release` | [署名・配布・ストア公開](mobile.release.md) | 共通 | ビルドと依存管理 |
| `mobile.cicd` | [CI/CD・静的解析](mobile.cicd.md) | 共通 | チーム開発、ビルドと依存管理 |
| `mobile.observability` | [監視・クラッシュ分析](mobile.observability.md) | 共通 | API連携とデータフロー、署名・配布・ストア公開 |
