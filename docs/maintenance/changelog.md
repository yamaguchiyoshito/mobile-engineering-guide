# 改訂履歴

## 1.0.0 — 2026年9月28日

- モバイル開発に不慣れな読み手向けに、「モバイルアプリ開発の前提」「学習の進め方」「用語集」と個人評価の記入例を追加。各要素技術のページに「この要素技術について」「次のLvへ進むために」、各チェック分野に「この分野の背景」を追加し、技術の対応表を用途別に整理。

- モバイルアプリ開発（iOS、Android、React Native）を対象とする初版。
- 4領域・34の要素技術・170定義の要素技術の定義と、25分野・100項目のチームチェックリストを収録。
- 評価手順、4種類の空の書式、架空の記入例、運用・改訂の手順を収録。
- GitHubの公開リポジトリと一般公開のGitHub Pagesを前提とする構成。日本語・要素技術ID・項目No.の検索、前後ナビゲーション、単一Markdownと書式のダウンロードを提供。
- PR検査、リリースタグによる公開、既存タグの再公開手順を収録。
