# 改訂履歴

## 1.0.0 — 2026年9月28日

- モバイルアプリ開発（iOS、Android、React Native）を対象とする初版。
- 4領域・34スキル・170定義のスキル定義と、25分野・100項目のチームチェックリストを収録。
- 評価手順、4種類の空の書式、架空の記入例、運用・改訂の手順を収録。
- GitHubの公開リポジトリと一般公開のGitHub Pagesを前提とする構成。日本語・スキルID・項目No.の検索、前後ナビゲーション、単一Markdownと書式のダウンロードを提供。
- PR検査、リリースタグによる公開、既存タグの再公開手順を収録。
